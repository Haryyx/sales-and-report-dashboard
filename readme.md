# 📊 Sales & Report Dashboard

An interactive **Sales Dashboard** built using **Microsoft Power BI and SQL** to analyze sales performance and generate meaningful business insights through interactive visualizations.

## 📌 Project Overview

This project transforms raw sales data into an interactive Business Intelligence dashboard.

SQL is used for working with the underlying sales database, while Power BI is used for data transformation, analysis, visualization, and reporting.

The dashboard allows users to explore sales performance across different business dimensions using interactive filters and visualizations.

## 🚀 How to Use

1. Clone or download this repository.
2. Open `sales_Dashboard.pbix` using **Microsoft Power BI Desktop**.
3. Restore/import the database using `db_dump.sql` if required.
4. Update the database connection if required.
5. Refresh the dataset.
6. Explore the dashboard using the available filters and visualizations.
